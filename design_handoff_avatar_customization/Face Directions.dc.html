Mechanism — faces are figuredata SETS, not stamps

Faces are new hd SETS — the model Habbo itself uses. hd stays one mesh forever (decision log 2026-08-05): every face set shares the identical skull render and differs only in its authored feature map, so hats stay non-combinatorial. New sets append (ids 17+), each declaring 2 slots: slot 0 skin (family "skin", as today), slot 1 iris, from a curated iris list (charcoal, walnut, oak, teal, fern, navy). The whites index the fixed paper ramp directly — never a slot, never player-facing. A shipped face is a CURATED combo of the axes on these boards (eyes + brows + mouth + extras), not free mix-and-match — that keeps the set count a catalogue, not a cross-product. Beards/moustaches/stubble ship as fa sets in hair colours, so they layer over any face.

Art is authored per-direction as pixel maps relative to FaceAnchor — the #311 registration machinery is exactly the reusable part. Three views drawn (front d3, three-quarter d2, profile d1); dirs 4/5 mirror about the anchor, shading-safe under B4. figurepass translates the map by the projected anchor per (frame, dir), so walk and sit cost nothing.

hd stays one mesh; the brow/nose interior prim lines and the old 4-px stamp are retired from hd2 (one intentional re-freeze — pixels are identity, this is the sanctioned path).

gateFace evolves — invariants kept

Every authored pixel must land on the skull prim (unchanged, via the same stamp check); front dirs 2/3/4 must stamp ≥ 1 white and ≥ 1 pupil pixel; back dirs 0/6/7 must stamp none; profiles 1/5 exactly one eye (new — today the rig decides, now it is asserted). A new feature-bounds check holds the whole block inside the skull's lower half so no future set can creep onto the cranium hats occupy.

Anchor registration measured off these boards (stand, dir 3): brow row y31, lid y33, eye rows y34–35, nose y36, mouth y39, chin y42 — i.e. the eye block sits 2 rows higher than the #311 stamp (y37), which is most of why the old face read low and sad.

Holdout consistency is untouched: faces paint only on hd2's own pixels, so gateHoldout's composite-equals-combined claim still holds bit-exact.
